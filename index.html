Shorts Bot

A personal desktop tool for scripting, composing, and cross-posting my own short-form videos.

What it does

Shorts Bot runs on my own computer. It generates a short script from a niche I pick, synthesizes a voiceover, stamps captions onto a 1080×1920 MP4, and then — only when I click Upload — pushes the finished file to my own YouTube and TikTok accounts.

  • Output: a single 1080×1920 vertical MP4 (max 60 seconds, YouTube Shorts / TikTok format).
  • Destinations: my own YouTube channel and my own TikTok account, only.
  • Every upload is user-initiated — there is no scheduled background posting unless I personally enable it on my own machine.

TikTok integration

Shorts Bot integrates with TikTok via the official developer APIs so I don't have to drag-and-drop files into the TikTok app every time I want to cross-post a Short.

  • Login Kit (scope user.info.basic) — one-time OAuth so the tool can act on my TikTok account.
  • Content Posting API (scope video.publish) — performs the FILE_UPLOAD publish flow: init → chunked PUT → status poll.
  • Creator Info query (scope video.upload) — fetches my account's posting limits before each upload so the tool doesn't exceed the daily cap.

Who uses it

Me. There is no public service, no server, and no shared account. Shorts Bot is a single-user desktop application I run locally. There are no third-party users and no data collection beyond what I produce and upload myself.
