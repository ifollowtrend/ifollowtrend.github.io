Privacy Policy

Last updated: April 21, 2026

Shorts Bot is a personal desktop application. It is installed and run by a single operator (me) on my own computer. It is not a service, a website, or a product offered to third parties.

What data the application collects

None from third parties. The application never asks for, accepts, or stores data from anyone other than its single operator. Specifically:

  • No account sign-ups.
  • No analytics or telemetry sent to me or to any third party.
  • No visitor data is collected on this website. This site is a static set of HTML pages hosted on GitHub Pages.

What data the application stores locally

  • My own content: generated scripts, voiceovers, and MP4s live in a folder on my computer.
  • OAuth tokens for my own accounts: YouTube and TikTok access/refresh tokens are stored locally so the tool can upload on my behalf. These tokens belong to my own accounts and are never transmitted anywhere except to Google's and TikTok's own APIs.

Third-party APIs

When I click Upload, the application calls:

  • YouTube Data API v3 — to upload a video to my own channel.
  • TikTok Content Posting API — to upload a video to my own account. Required scopes: user.info.basic, video.publish, video.upload.

Each provider's own privacy policy governs how they handle those requests on their side.

Data sharing

Nothing about this tool shares user data with anyone, because there are no users other than me. I do not sell, rent, or otherwise disclose any information to third parties.

Changes

If this policy changes I'll update the "Last updated" date at the top of this page.
